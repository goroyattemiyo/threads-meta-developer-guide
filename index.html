このガイドでは、Threads投稿ツールを使うための初期設定を画像付きで説明します。初めての方でも10〜15分で完了できます。

この手順はPCのブラウザ（Chrome推奨）で行ってください。認証が完了すれば、その後の投稿や予約などの操作はスマホから行えます。

ステップ1: Meta for Developersにログイン

Meta for Developersを開く

  1. 右上の「ログイン」をクリック
  2. Threadsで使っているFacebookアカウントでログイン

ステップ2: 2段階認証を設定（初回のみ）

  1. 携帯電話番号を入力、送信
  2. SMSで届いた6桁のコードを入力
  3. メールアドレスを認証
  4. その他を選択して完了

ステップ3: アプリを作成

  1. 右上の「マイアプリ」をクリック
  2. 「アプリを作成」をクリック
  3. 好きなアプリ名を入力
  4. ユースケースで「Threads API」を選択
  5. 「現時点ではビジネスポートフォリオをリンクしない」を選択
  6. 要件を確認してダッシュボードへ移動

ステップ4: アクセス許可を追加

  • threads_basic
  • threads_content_publish
  • threads_manage_insights
  • threads_manage_replies

ステップ5: テスターを追加

  1. ユースケースの設定を開く
  2. 「Threadsテスターの追加または削除」を選択
  3. 自分のThreadsユーザー名を入力（@は不要）
  4. 表示された自分のアカウントを追加

ステップ6-2: 招待を承認する（重要）

  1. スマホでThreadsアプリを開く
  2. 設定を開く
  3. アカウント → ウェブサイトのアクセス許可
  4. 「テスター招待」を承認

ステップ7: リダイレクトURIを設定

  1. ユースケースの「設定」を開く
  2. Threads投稿ツールに表示されたリダイレクトURIをコピー
  3. Meta側のリダイレクトコールバックURLへ貼り付け
  4. アンインストール・削除用コールバックにも同じURLを設定
  5. 保存

ステップ8: アプリIDとシークレットを確認

  1. 「アプリ設定」→「ベーシック」を開く
  2. ThreadsアプリIDをコピー
  3. App Secretを表示してコピー
App Secretは絶対に他人へ送らないでください。

設定完了

これでMeta Developerの設定は完了です。

トラブルシューティング

  • Threadsテスターの招待を承認したか確認
  • リダイレクトURIが正しくコピーされているか確認
  • Threadsと同じFacebookアカウントでログインしているか確認
